## 数据库回归的运行方式

提供专用 PostgreSQL 测试实例，并让测试账户具有创建数据库权限：

```sh
FLAI_TEST_POSTGRES='postgres://test_user:test_password@127.0.0.1:5432/postgres' go test -race ./...
cd frontend
pnpm test
pnpm build
```

测试为每个测试进程创建独立随机数据库，结束后删除；未设置 `FLAI_TEST_POSTGRES` 时，数据库用例会明确跳过。不要把测试变量指向业务实例。

## 后续回归：开发环境新会话首条消息被取消

用户反馈新会话 `/api/messages` 在会话查询阶段出现 `context canceled`。定位到 React Router 默认开发入口启用 StrictMode，初始化 effect 的重放会立即执行新增的请求清理，而首条消息草稿已被消费，导致请求被取消且没有重新发送。

已将初始化放到可取消的微任务中：被清理的 effect 不消费草稿、不启动请求；实际保留的 effect 只发送一次。真实切换会话/卸载时仍会取消旧订阅。新增 StrictMode 首条消息回归，先验证旧实现会取消请求，再验证修复后仅发送一次并正常合并回复；前端回归现为 16 项，类型检查通过。
